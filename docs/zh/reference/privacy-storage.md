# 隐私与存储

## 哪些内容留在本机

桌面版中的画布、模型凭证、导入文档和本地 session 镜像都保存在你的机器上。画布状态使用 IndexedDB；可选文件夹备份则写入明确的 `.thoughtdag.json` 文件。

## 哪些内容可能离开设备

只有需要传输的功能会把内容送出设备：

- 向远程 endpoint 发起模型请求；
- 使用搜索或外部工具；
- 创建并发送分享 URL；
- 把备份文件夹交给第三方同步服务；
- 把导出文件发送给他人。

普通阅读时 PDF 留在本机。被选入远程模型请求的提取文字或材料可能会发送给对应 endpoint。

## 凭证

界面中配置的 key 保存在本地浏览器存储和代理内存中，不进入普通画布备份。你仍需检查所连接模型或工具服务的隐私政策。

## why 层留下的索引

早期版本带有 why 层（命令行、MCP 工具和 Harness 工具），会把本机 Agent 会话索引到 `~/.thoughtdag`。这项功能已经移除。如果你用过它，下面这些文件不会再被读取，可以手动删除：`fact-index.json`、`text-index.json`、`text-index.jsonl`、`interpretation-cache.json` 和 `canvases/` 目录。`workspaces/` 要保留，Agent 轮次在那里运行。删除索引不会影响原始会话。

## Harness 插件

嵌入画布使用 Harness 网页来源下的浏览器存储；模型配置、凭证和会话日志由 Harness 管理。插件访问的是运行 Harness 的机器上的受支持日志，不一定是浏览器所在设备。

Agent 调用查询工具后，命中的历史内容可能进入其下一次模型请求；使用远程模型时，这些内容可能发送给相应服务。通过 **DeepSeek Harness · Agent** 发出的新轮次会写入 Harness 会话日志，编辑画布不会删除那份日志。

## 在线 Demo

在线 Demo 的画布保存在浏览器本地，支持时使用浏览器直连模型。它不包含完整的桌面本地能力。
